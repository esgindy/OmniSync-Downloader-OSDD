## OmniSync Downloader (OSDD) v1.0.0 — الإصدار الأول

- تنزيل مباشر من SharePoint ملفاً بملف بدون ضغط Zip.
- استعراض المجلدات، تحميل متوازٍ مع استئناف عند الانقطاع، ومقارنة مزامنة وتحقق من السلامة.
- واجهة ويب محلية تعمل على جهازك.

First public release: direct file-by-file SharePoint download, folder browser, parallel resumable transfers, delta sync and integrity audit, in a local web UI.
