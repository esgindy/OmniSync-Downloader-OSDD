## OmniSync Downloader (OSDD) v6.0.0 — مراجعة التكرار

**تاب جديد: مراجعة الملفات المكررة**
- فحص مسار A (ومسار B اختيارياً) للعثور على الملفات المتطابقة داخل المسار الواحد وبين المسارين.
- اختيار المكان الذي يبقى: A أو B أو الأقدم أو الأحدث أو أقصر مسار، مع حماية يدوية لأي ملف.
- معاينة قبل الحذف، ثم نقل المكرر إلى **سلة المحذوفات** (وليس حذفاً نهائياً)، مع إعادة التحقق من الحجم وSHA-256 قبل كل ملف.
- أزرار اختيار المجلد بجوار المسارين، وواجهة بثماني لغات، و20 اختباراً جديداً (75 إجمالاً).

New Duplicates review tab: scan one or two paths, choose which location stays, preview, then move duplicates to the Recycle Bin with per-file re-verification.
