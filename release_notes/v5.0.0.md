## OmniSync Downloader (OSDD) v5.0.0

**الأمان:** فحص Origin/Host لكل طلب، إيقاف آمن (graceful shutdown)، ومراقب نبضات لا يغلق الخادم أثناء وجود مهمة نشطة.
**الأداء:** HTTP/2، backoff أسي مع Retry-After، تحميل متوازٍ بأجزاء Range للملفات الكبيرة، حد سرعة، وكتابة القرص خارج حلقة الأحداث (لا تجمّد الداشبورد على الأقراص الخارجية).
**المزامنة:** مقارنة سريعة (الحجم والوقت أولاً ثم hash للمشكوك فقط)، Dry-run، كشف الملفات المكررة، واختيار ملفات محددة قبل التحميل.
**الواجهة:** تابات، لوحة مؤشرات وخط سرعة، خمسة ثيمات + تلقائي، حتى 10 عاملين، ثماني لغات.
**الميزات:** فلاتر (امتداد/حجم/تاريخ/regex)، طابور مهام، جدولة مزامنة، إشعارات ويندوز/Telegram، سجل مهام SQLite.
**الجودة:** CI على GitHub Actions وruff وملف requirements.lock.txt و55 اختباراً.

Security (Origin/Host guard, graceful shutdown), performance (HTTP/2, parallel Range, speed limit, non-blocking disk I/O), fast sync with dry-run and duplicate finder, per-file selection, themes, filters, queue, scheduler, notifications, SQLite history, CI.
